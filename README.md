# 💍 2027 Romantic Honeymoon Odyssey

2027년 3월 21일 예식 직후 출발하는 3주간의 프리미엄 신혼여행 프로젝트 웹 대시보드 및 가이드북입니다.  
에미레이트 항공 비즈니스 클래스 혜택, 두바이 커넥트 5성급 호텔 1박(JW 메리어트 마르퀴스 두바이), 스페인·포르투갈 3주간의 로맨틱 여정을 인터랙티브 웹 대시보드로 구성하였습니다.

## 🌟 주요 기능

1. **인터랙티브 루트 지도 (Leaflet.js)**:
   - 각 도시 마커 및 경로선(Polyline) 바로 위에 **이동 수단 및 이동 소요 시간** 상시 표시
2. **한눈에 보는 종합 마스터 표 (Master Schedule Table)**:
   - 22일간의 전체 일정을 `☀️ 오전`과 `🌙 오후/저녁` 일정으로 분리 표기
3. **실시간 예산 산출기 & 체크리스트**:
   - 항목별 숫자를 조절하면 실시간으로 총 예산이 렌더링되는 인터랙티브 산출기
4. **단일통합 공유 HTML 파일 (`wedding_trip_shareable.html`)**:
   - 외부 서버 없이 이 HTML 파일 하나만 상대방에게 전달하면 카카오톡/스마트폰 브라우저에서 바로 열리는 완벽한 공유 웹 대시보드

## 📥 저장소 가져오기 (GitHub Clone)

새로운 PC에서 이 프로젝트를 내려받아 작업하려면 아래 명령어를 실행합니다:

1. **Git 설치**: [Git 공식 홈페이지](https://git-scm.com/)에서 PC 환경에 맞는 Git을 설치합니다.
2. **저장소 복제**:
   ```bash
   git clone https://github.com/Fizz-Trickster/2027_honeymoon_spain_portugal.git
   ```
3. **프로젝트 폴더로 이동**:
   ```bash
   cd 2027_honeymoon_spain_portugal
   ```

## 🚀 로컬 실행 방법

Node.js 환경에서 간단한 서버나 브라우저로 실행할 수 있습니다:


```bash
# 8080 포트로 실행 시
npx http-server -p 8080
```
